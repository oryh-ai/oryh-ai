# 真正的 FDE，普通公司养得起吗？

*《当 Agent 开始操作企业》· 研发随笔*

如果一个人既懂行业，能看穿客户组织里的实际责任，又有工程能力，能在生产环境里独立处理 Agent 的风险，还愿意长期驻场，他的成本不可能按普通实施工程师算。真正的 FDE 若是这样的人，普通公司首先要问的不是“能不能找来”，而是“这个项目值得长期买下他的时间吗？”

我不打算编一个日费率。不同城市、行业、项目差太多。光把成本摊开看，问题已经很明显。

## 买的不是一张工位

客户付的钱不只是一位工程师坐在办公室的工作日。前面有售前调查，项目里有差旅与在场时间，背后还要有产品、架构和安全团队支持。现场碰到需要回产品修的缺口，要有人开发和测试；碰到业务争议，要有人一起做访谈与确认。上线后规则变化、人员离开、系统报错，也要有人接。

若这位 FDE 真能横跨业务和技术，供应商还要承担招聘、培养、留任的成本。让他一个项目待几个月，其他客户就用不了他。空档时间也不可能凭空消失，最后会分摊到项目报价里。

一个中小企业可能只想让销售订单、采购和简单审批跑顺。它当然应该得到可靠系统，但未必值得为此长期购买一位资深超级个体的专属时间。把这种投入硬塞给客户，像给一辆日常通勤车配一支赛车维修队：队伍很强，账却不合适。

还要算客户自己的投入。现场专家到来后，不是他一人把系统变出来。销售、财务、仓库要陪访谈、整理旧单据、确认规则；关键人开会的时间也是成本。如果这几位本来就很忙，再派一位高价专家天天等他们回答问题，项目可能两头都浪费。先让软件承接稳定的记录，再把少量真正需要判断的环节集中讨论，常比无限期驻场划算。

反过来，大型、高风险或高度特殊的项目可能确实值得请这样的人。一次误付款或交付事故的代价很高，资深现场判断能减少更大的风险。讨论“养得起吗”，不是说所有客户都买不起，而是要把项目收益、风险下降与完整投入放在同一张账上。

## 哪笔收益归这个人，先算明白

销售话术常说“FDE 能让 AI 落地”，却很少说落地以后每个月少了什么损失。若原来要三个人反复核对订单，部署后仍要三个人盯着 Agent 的每次建议，只是换成在新界面里点确认，节省了多少？若流程确实快了，但异常处理变慢了，也得一起算。

真正有价值的指标应贴着业务：漏发货减少了吗，重复付款拦下了吗，审批等待时间变短了吗，新规则生效是否不再要等一轮开发。还要看稳定运行几个月，而不是演示当天处理了一百张样本单。

一位昂贵的现场专家若帮客户找到了关键误区，比如“可用库存”一直把已占用的货算进去，价值可能远超过他的在场成本。但发现以后，修复应进入产品和记录体系。若每次查询都必须由他亲自盯着，客户买的是一位长期人工守门员，不是可持续的软件能力。

所以客户可以把投资分成两段看。第一段是上线：旧数据是否正确进来，流程能否跑，权限有没有守住。第二段是离场后的半年：业务规则变了，谁来改；Agent 做错一次，谁能查到依据；产品升级，原有逻辑还能不能用。很多报价只把第一段写得详细，第二段用“持续支持”四个字盖过去。真正贵的恰恰可能藏在这四个字里。

## 让成本从“一个人专属”回到产品

更合理的路径，是把重复出现的硬问题做成产品能力：记录、权限、金额合计、版本、审计、数据迁移工具。把企业自己会变的判断留在自然语言规则里，让 Agent 按当前事实执行。这样同一位资深专家解决过的一类问题，下一位客户不必从头付一次完整的驻场账。

这不意味着专家消失。他可能参与最难的客户、设计交付方法、复核高风险部署，再把现场学到的东西反馈给产品。区别在于客户买的主要是能长期使用的软件，而不是必须一直在场的个人。

有些问题不能摊薄，例如高度机密的集成、独特的供应链或复杂组织变革。那就如实报价，说明买的是高阶服务。不要一边告诉普通客户“这是标准 AI 产品”，一边把交付建立在长期专属 FDE 身上，最后再为价格吵架。

更灵活的买法可以是短期专家诊断、明确范围的上线复核、关键流程定期抽查，日常运行由产品、客户团队和普通支持人员承担。不是每家公司都需要一位全职资深人士坐在隔壁；但高风险节点需要专家时，也不能为了省钱拿初级人员冒充。把时间用在刀刃上，才谈得上普通公司用得起企业 AI。

## 没有数字，也能把账问清

客户可以要求供应商分开列：产品订阅或许可、数据迁移、接口开发、现场驻留、上线后支持、因客户特殊规则产生的额外工作。现场人员的级别和实际投入多久，也要明说。报价不必公开给全市场，但客户至少能知道自己买的是什么。

再问换人之后怎样运转。若那位专家离开，规则和判断依据留在哪里？新员工能否接续？产品升级是否会冲掉他写的客户专用代码？这些是投资回收的一部分。花很多钱买来一个只有本人能维护的部署，算账时不能只看首期验收。

做 Oryh 时，我们尽量把确定性记录和硬约束做进软件，把客户的流程逻辑交给 Agent 读自然语言规则。这个方向不保证所有项目都便宜，却至少在努力把一次现场判断沉淀为可复用的产品和可追溯的规则。真正的 FDE 值得高价；问题是普通客户不应为了弥补产品还没做完的地方，长期供养一个如此昂贵的人。
